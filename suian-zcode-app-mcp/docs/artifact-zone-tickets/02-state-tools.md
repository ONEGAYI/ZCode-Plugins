# 工件区：用当前会话工具增量维护持久状态

本地标识：AZ-02。GitHub：[#28](https://github.com/ONEGAYI/ZCode-Plugins/issues/28)。状态：实现票受阻，尚未实施。Blocked by：[#27](https://github.com/ONEGAYI/ZCode-Plugins/issues/27)。只有该票证实请求级投影和分叉快照入口可用，才可解除阻塞；否定调研结论或仅关闭该票均不能解除本条件。

## 问题与交付

Agent 用 get_artifacts 读取当前会话状态，用 set_artifacts 仅提交变动引用。状态重启后仍在，多个 MCP 进程不能因过期版本相互覆盖。

负责范围：app-mcp 的工件状态/投影生成模块、server/cli 接线、现有测试 fixture 和工具说明；复用 caller，保持其它工具的既有来源处理语义。

## 验收条件

- [ ] 新增两个工具，仅绑定唯一定位的当前会话，不接受目标 session_id；缺失或歧义来源明确报错，不写候选会话。
- [ ] 四类条目仅含 kind/ref/label/purpose；同一 ref 更新或移除，增量批次符合规格中的顺序和输入约束。
- [ ] 同一事务检查 expected_revision、容量并保存；旧版本并发写入、无效批次或超限不产生部分结果。
- [ ] 有变化才增加 revision；成功回执只有版本、changed 和实际变动数量，不回传完整集合。
- [ ] 20/21 条、完整投影 12000/12001 Unicode 码点边界及中文/emoji 场景符合契约；固定说明也计入容量。
- [ ] 首次读取空状态不创建写存储；持久状态重启可读，已存在但损坏/不可读的存储明确失败。
- [ ] 使用插件自有隔离 SQLite，不写 ZCode 会话库，不依赖原 Host 连接来维护工件，不把状态放进公共网关。
- [ ] 从真实 MCP 公开入口写契约测试，先观察红灯再实现；并发测试使用独立连接或进程，不仅测试同一对象的方法调用。

标准测试入口沿用本项目 npm test；首次执行保存日志与退出码。新存储路径注入 fixture，不能让已有测试打开真实工件数据库。

接口、计数与生命周期：[工件区规格](../artifact-zone-spec.md)。
