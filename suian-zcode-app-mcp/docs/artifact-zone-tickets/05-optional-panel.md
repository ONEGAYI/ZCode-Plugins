# 工件区：可选外挂只读网页面板

本地标识：AZ-05。GitHub：[#31](https://github.com/ONEGAYI/ZCode-Plugins/issues/31)。状态：可选后续，尚未实施，不默认执行。Blocked by：[#28](https://github.com/ONEGAYI/ZCode-Plugins/issues/28)；不作为首版完成条件。

## 问题与交付

用户通过按需启动的本地网页显式选择会话，查看同一份工件状态。界面展示和刷新无需调用模型，当前路线不依赖 ZCode 原生面板注册或选择事件。

负责范围：app-mcp 配套的按需本地 UI 进程与只读页面、状态访问接线和隔离 UI 验证；不为展示占用长期 Host 桥，不复制一套工件状态。

## 验收条件

- [ ] 用户明确选择会话，页面清楚显示正在查看的会话；切换两段会话不串读，不用 MCP 来源、最近会话或 membership.active 冒充界面选中项。
- [ ] Agent 更新后显式刷新或有限轮询显示对应 revision，重启读取同一状态；不调用模型或轮询聊天正文。
- [ ] 首版页面只读，支持普通 PR/网页链接、面板内切换关联会话和复制文件路径。
- [ ] 不承诺跳转 ZCode 内部会话、自动跟随或系统打开文件；如需增加，先核实对应入口并另行审阅范围。
- [ ] 浏览器不直连公共网关、不拿到网关 token；若以后需要 Host 操作，由进程端按现有边界调用。
- [ ] 明确按需进程的启动和停止方式；Windows 后台启动隐藏窗口，运行日志首次落盘。
- [ ] 通过隔离会话状态进行 UI 检查，验证刷新、空状态、错误提示和网页/路径呈现；没有实际运行不得记为验收通过。

路线与证据：[外挂面板研究](../artifact-panel-external-research.md)、[原生面板研究](../artifact-panel-native-research.md)。外挂面板不会解除 AZ-03 的宿主投影依赖。
