# 工件区：主动登记、更新与清理的提示词及验证

本地标识：AZ-04。GitHub：[#30](https://github.com/ONEGAYI/ZCode-Plugins/issues/30)。状态：实现票受阻，尚未实施。Blocked by：[#29](https://github.com/ONEGAYI/ZCode-Plugins/issues/29)。

## 问题与交付

仅提供状态工具不能保证 Agent 会主动使用。将已审阅的固定管理提示词纳入投影，验证 Agent 是否登记关键引用、使用增量更新并清理失效项，避免把容量上限当作填写目标。

负责范围：app-mcp 的工件管理提示词、skill 说明和行为评估证据；不追加第三个管理工具，不自动操作引用对应的资源。

## 验收条件

- [ ] 提示词明确四类、四字段、按 ref 更新、版本校验、20 条和完整投影 12000 码点上限，通常使用投影而非重复 get。
- [ ] Agent 成功创建或接手需持续访问的 PR/关联会话/关键文件时主动登记，有清晰 purpose；普通临时文件或偶然访问页面不被全量登记。
- [ ] 同一引用的新名称/用途使用增量 upsert，不重复条目、不重发整份集合；成功回执保持简短。
- [ ] 完成但仍需交付或接续查看的工件保留；被替代或失效且无用途的引用移除，真实资源不被删除。
- [ ] 冲突时以最新投影或显式 get 为准，容量不足先整理再提交；不以旧快照覆盖或静默丢弃有用引用。
- [ ] 工件引用不被解释为外部发信、推送、合并或资源操作授权。
- [ ] 固定代表性场景、模型/配置、工具输入输出与评价标准，给出真实观察结果和失败场景；不以确定性 mock 回复冒充模型主动管理证据，不承诺每次必然遵循。
- [ ] 记录实际工具输入/回执体积和投影体积，不凭字符数声称精确 token 或缓存成本。

管理提示词和技术保证边界：[工件区规格](../artifact-zone-spec.md)。行为评估用合成资源和受控工具，不对真实 PR/会话进行未授权操作。
