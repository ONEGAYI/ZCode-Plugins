# 工件区：核验请求级投影与分叉快照入口

本地标识：AZ-01。GitHub：[#27](https://github.com/ONEGAYI/ZCode-Plugins/issues/27)。状态：调研完成，当前正式插件能力不足；工件功能尚未实施。Blocked by：无。

## 问题与交付

开票时，公开 3.14.3 的 additionalContext 会追加运行时历史，配置型 Hook 没有请求级尾部槽或分叉事件；安装包 UI 静态复核仅确认本机版本为 3.14.5。后续隔离验证已完成，当前能力不足，结果见下方核验报告。

固定实际发行版、启动方式、CLI 产物和隔离工作区，给出插件能否满足严格目标的原始证据及明确结论。失败结论也是有效调研成果，不能用插件自行拦截模型网络或改造运行时冒充宿主已有能力。

负责范围：app-mcp 的隔离研究探针与脱敏证据；官方 sources 和本机发行文件只读。

## 验收条件

- [x] 记录版本、执行目录、启动方式和实际 CLI 产物，区分隔离 CLI 与真实运行中的 Desktop。
- [x] 确认或否定可用的插件请求级入口，覆盖连续用户输入、工具续跑、状态变动、重试、压缩与恢复路径；不只凭方法字符串声称支持。
- [x] 捕获实际 provider 请求，检查自动投影的来源、数量和 messages 最后位置；同时检查运行时及持久化恢复数据不保留自动投影。
- [x] 确认或否定分叉操作时的父子身份与冻结快照入口；检查父状态在子会话首次请求前变化的情形。
- [x] 未公开或不能执行的路径明确标为未验证，不写为通过。
- [x] 若能力缺失，记录所需宿主契约与上游/版本依赖，后续实现票保持受阻；不降级为按轮次追加。
- [x] 验证只用隔离配置、数据库与合成会话。长命令首次保存日志和退出码，留下脱敏汇总，不改真实用户设置或活动会话。

依据与目标：[工件区规格](../artifact-zone-spec.md)、[Hook 与分叉源码证据](../artifact-zone-design.md)。公开规格全文附于本票。
