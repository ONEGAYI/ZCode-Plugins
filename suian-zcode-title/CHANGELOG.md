# 更新记录

## [0.4.0] - 2026-11-04

自动命名会读取长回复和后台任务的收尾内容。标题样式可以通过本地提示词配置。

### 新功能

**本地提示词配置（#192、#193）**

- 首次运行部署本地 Markdown 提示词，Stop 检查 YAML 中的 `version`。手动设为负整数可固定自定义稿。
- 升级和恢复保留一份滚动备份。恢复无效文档后，系统通知提供文件定位入口。
- Emoji、分隔符、长度和状态标记由本地提示词决定。插件保留模型响应结构和敏感内容检查。

### Bug 修复

**命名上下文与输出纠错（#192、#193）**

- 超长助手回复保留首尾，默认正文配额为 2000 字符，首尾比例为 40% 和 60%。配额和比例可配置。
- 后台任务通知后的可见助手回复归入对应真人轮次，模型能读到最终结果。
- 模型输出无效时，在同一时间预算内最多纠错两次，并区分输出错误、输入事件错误和配置错误。

> **升级说明**　提示词恢复通知依赖 common 0.10.0 提供的能力和已登记的通知资产。升级后按 setup 核对登记。

> **验证范围**　契约测试覆盖命名、版本部署、备份和通知动作。真实 ZCode Stop 改名和 Windows 通知点击待桌面验收。

## [0.3.0] - 2026-10-30

修复会话回退后自动命名遗漏新分支内容的问题，并在命名模型配置不可用时提供排障提醒。

### 新功能

**模型不可用提醒（#178）**

- 所选模型或思考档位不在原窗口可用目录时，Stop 命名任务通过通知提示并提供可复制的排障提示词。
- 通知提供 24 小时免打扰，保持用户原有模型选择，不自动改选。

### Bug 修复

**回退后的命名历史（#176、#177）**

- 兼容 `conversation_rewind` 的分支切点，保留回退前有效前缀与后续新分支消息。
- 继续支持旧回退格式；找不到切点时不重新纳入已废弃分支，也不放宽系统注入消息的过滤。

> **验证范围**：历史裁剪契约已验证，真实手机普通会话已完成命名验证；真实手机回退后继续输入的完整场景仍待验收。模型目录可用但运行时请求失败的情况沿用已有网关错误分类。
