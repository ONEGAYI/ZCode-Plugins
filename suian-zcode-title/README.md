# suian-zcode-title

让 ZCode 的会话标题跟上你正在做的事情。每轮对话结束后，自动参考最近三轮内容更新标题，会话再多，也更容易找回。

升级会保留既有配置和暂停状态；定时任务冻结的标题不会被误判为手动改名，已有锁定状态继续保留，确认误锁后可用 unlock 命令处理指定会话。

版本与兼容范围以[实际发布页面](https://github.com/ONEGAYI/ZCode-Plugins/releases)和安装时的反馈信息为准。

安装和升级时，Agent 会按 Desktop 应用版本选择适用的网关协议；日常重载会保留已有协议与用户配置。具体方法与限制见[公共网关配置说明](../suian-zcode-common/skills/configuration/SKILL.md)。

## 一眼看出每个会话在做什么

| 原来的标题 | 自动命名后 |
| --- | --- |
| C:/Users/…/handoff-zcode-title-202610…（被截断的临时文件路径） | 🧩 远控 Hook 插件｜授权失效排查 |
| 检查主树脏文件决定保留或推送 | 🧩 Git 工作树｜脏文件清理 |
| 帮我看看这个报错 | 🧪 发布流水线｜超时排查 |

默认提示词建议采用「类别 emoji + 对象｜目标」，先说处理的对象，再说要完成的事；可在状态目录自定义提示词：

- 对象在前：模块名、工具名或内容主题，不以"修复""优化"这类动作开头
- 用图标区分类别，例如工具开发、工程验证、项目协作，方便浏览会话列表
- 名称稳定：补测试、提交代码这类后续动作不会改动标题，你明确转向新工作时才更新
- 跟随语言：中文对话用中文标题，英文对话用英文标题
- 由你控制：可以暂停自动命名，也可以要求 Agent 固定某个会话的名称

## 基于官方 Web 远控通道

插件通过 ZCode 自带的「移动端远程控制」连接当前窗口。标题在后台生成，再由 ZCode 完成更名，对话中不会插入命名消息。

安装时，Agent 会同时配置公共网关，它是供插件和手机共用的后台连接程序。按提示在桌面端的移动端远程控制面板开启服务，出现等待连接或已连接的状态后，再检查插件是否可用。插件不要求手机扫码或保持在线，也不需要接收手机远控链接。

每轮对话结束后，插件会参考最近三轮内容，使用你账号里所选的模型判断是否需要调整名称。主线没有变化时可以保留原名。首次安装从实际清单选择模型与思考档位，示例配置不代替用户选择。

命名提示词部署在状态目录的 `naming-prompt.md`，不会随插件缓存清理消失。版本升级、备份、锁定和重置方式见[配置说明](./skills/configuration/SKILL.md)。

### 内网机器能使用吗

让 Agent 按[公共 setup](../suian-zcode-common/skills/setup/SKILL.md)检查 local-only 的可用性。该模式由网关在本机提供连接，不提供官方手机连接，所选模型服务仍需可达。先完成配置，再按安装反馈安排重启与连接检查。

### 会不会影响手机远程控制

**手机可以继续连接**。公共网关把手机操作和插件请求转到同一个 ZCode 窗口，插件不会用另一个设备的身份接管手机连接。

3.16 的在线共存和后台生成标题已通过验证，手机连接期间的完整自动命名流程仍待验证。

手机远控本机项目的时候，插件可以同时操作。只有手机切换到**远程开发工作区**（例如通过 SSH 或 WSL 连接打开的项目）时，目前才无法同时完成本地自动命名。这里指的是项目的运行环境，开启手机远控本身不会触发这项限制。

**安装和升级可以留在当前 ZCode 会话里完成**。需要重载后台连接程序时，Agent 会自动避开进行中的远控操作：空闲时直接切换，Desktop 连接层自动重连；持续忙碌时最多等待约一分钟，可稍后重试或暂停远控让出窗口。应用和当前会话继续保留。首次接入或修改启动地址也先完成配置与本机检查，最后才提示你保存工作、择时重启生效。

## 原生插件与技能

通过根目录的[插件市场](../marketplace.json)安装本插件，公共依赖会自动安装。再让 Agent 按[setup](./skills/setup/SKILL.md)初始化；原生 Stop Hook 与技能由宿主加载，配置和状态保存在插件数据目录，安装器不重复写全局 Hook。

日常操作分别使用[configuration](./skills/configuration/SKILL.md)配置模型，[control](./skills/control/SKILL.md)暂停或固定标题，[debug](./skills/debug/SKILL.md)排查命名和通知。旧源码安装可迁移，setup 保留既有选择和状态，只移除指定旧根的注册；可复制根 README 的[迁移提示词](../README.md#旧源码安装迁移)或[原生升级提示词](../README.md#原生插件升级)。

## 源码安装或升级

直接在 ZCode 对话里粘贴下面这段，**无需先手动克隆**。同一提示词支持首次安装和升级，由 Agent 先询问操作、检查已有安装，再获取代码。

```text
请帮我安装或升级自动命名插件 suian-zcode-title：
https://github.com/ONEGAYI/ZCode-Plugins.git

先询问我是首次安装还是升级，以及源码放在哪里。
先检查已有源码和安装位置，优先复用现有仓库；没有时再确定克隆目录。
确认后，由你克隆或更新代码。首次安装按根 README 的“代码获取范围”使用稀疏检出，
获取 suian-zcode-title、公共 suian-zcode-common 和仓库根文件，不初始化 sources 子模块。
已有仓库保留其他已安装插件的目录；更新遇到本地修改或分叉时先说明，不强制覆盖。

读取仓库中最新的 suian-zcode-title/SKILL.md，
公共层统一按 suian-zcode-common/SKILL.md 配置，复用同一网关，
保留已有授权、模型选择和其他配置。
首次安装先获取当前 ZCode 实际可用的模型和思考档位，让我选择；
我已明确指定时，核验可用后沿用。升级保留并核验已有选择，需要更换时再询问。
宿主暂未连接时，标记模型配置待确认，保留当前会话完成其他配置，
待重开并连接后继续选择和核验；首次安装确认前保持自动命名暂停，不直接采用示例模型或宣称配置完成。
保留当前 ZCode 和会话，先完成全部安装或升级以及本机检查。
需要重载网关时，由你在当前会话按公共技能执行安全的 Restart；忙时自动等待，必要时再让我暂停远控让出窗口。
首次接入或修改启动地址也先完成配置，最后才提示我保存工作、择时重启生效；
地址未变且已连接正确网关时，重新开启远控即可。不要自行退出或重启 ZCode。
```

本插件的获取范围是 **自动命名目录 + 公共层 + 仓库根文件**，可以不检出 MCP。克隆命令与已有稀疏检出的扩展方式统一见 [根 README 的代码获取范围](../README.md#代码获取范围)。如果也要安装 MCP，可使用根 README 的组合提示词，由 Agent 询问插件选择。

## 日常怎么用

装好后不需要管它。想让 ZCode 做这些事的时候直接说：

- 「暂停会话自动命名」「恢复会话自动命名」
- 「命名插件换个模型」——更换生成模型或思考档位
- 「命名插件检查一下」——检查连接、配置和最近一次命名结果
- 「命名通知总是弹」「通知点了没反应」——通知排障

连接出了问题，插件会弹出 Windows 通知，同类提醒两小时内最多一次。点击通知按钮可以复制排障说明，再让 ZCode 协助处理。

## 使用前需要知道

- 适用于 Windows 10/11，需要 Node.js 24+ 和 sqlite3 命令行程序。安装器会先检查依赖和 SQLite 查询能力；缺少时明确报错，Agent 补齐并复查后才继续配置。
- 首次安装后，先在新建会话中使用；安装前已经打开的会话还没有加载新的自动命名配置。
- ZCode 需要保持运行并开启远控。关闭窗口可能只是隐藏到托盘，完整退出后无法命名。
- 标题生成使用你自己的模型额度，每次用量会保存在本机，可以让 Agent 帮忙查看。
