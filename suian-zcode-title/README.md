# suian-zcode-title

让 ZCode 的会话标题跟上你正在做的事情。每轮对话结束后，自动参考最近三轮内容更新标题，会话再多，也更容易找回。

## 一眼看出每个会话在做什么

| 原来的标题 | 自动命名后 |
| --- | --- |
| C:/Users/…/handoff-zcode-title-202610…（被截断的临时文件路径） | 🧩 远控 Hook 插件｜授权失效排查 |
| 检查主树脏文件决定保留或推送 | 🧩 Git 工作树｜脏文件清理 |
| 帮我看看这个报错 | 🧪 发布流水线｜超时排查 |

标题统一为「类别 emoji + 对象｜目标」，先说处理的对象，再说要完成的事：

- 对象在前：模块名、工具名或内容主题，不以"修复""优化"这类动作开头
- 类别固定十种：🎬 内容制作、🧩 工具开发、🧪 工程验证、📋 项目协作、🔎 对比调研、🎨 页面设计、📝 方法整理、📅 日程安排、⚙️ 环境配置、💬 一般讨论
- 名称稳定：补测试、提交代码这类后续动作不会改动标题，你明确转向新工作时才更新
- 跟随语言：中文对话用中文标题，英文对话用英文标题
- 由你控制：手动改过的标题不会再被自动命名覆盖，想恢复时对 ZCode 说一声即可

## 基于官方 Web 远控通道，不动你的对话

命名不往对话里插入任何消息，也不直接写 ZCode 的数据库：

1. 你在 ZCode 桌面窗口开启「移动端远程控制」，把生成的授权链接交给插件一次。链接用 Windows 账户加密（DPAPI）保存在本机，不进日志，不进配置。
2. 每轮对话结束，ZCode 的 Stop Hook 启动一个独立后台进程，通过官方 Web 远控通道连回当前窗口。
3. 后台进程用你账号里实际可用的模型（默认 GLM-5.3-Flash 低速档，可换）读最近三轮，生成标题后调用官方改名接口写回，几秒内完成并断开。

### 会不会影响手机远程控制

同一授权链接同一时刻只容一个连接，先连上的一方持有，后连的一方会被服务端拒绝。据此：

- 命名只占用几秒到几十秒的连接，完成即断开，手机随后就能连上。
- 命名发生时你正用手机连着：那一次命名会失败，手机不受影响，下一轮对话结束自动再试。
- 手机恰好在命名那几秒发起连接：手机连接会被拒绝，等命名连接结束后重试。
- 链接失效后插件会弹 Windows 原生通知提醒，点按钮即可复制排障提示词并打开 ZCode。

初始化现在会调用同仓库 [公共网关 skill](../suian-zcode-gateway/SKILL.md)，统一配置后台网关和 Desktop 环境变量。已验证的共存范围是 bootstrap 元数据读取；命名插件仍使用独立 terminal，完整 RPC 分流尚未接入，以上席位限制仍适用。

## 让 ZCode 帮你安装

先把仓库克隆到本地任意位置，然后在 ZCode 对话里粘贴：

```
帮我安装自动命名插件 suian-zcode-title。仓库已克隆到 D:\path\to\ZCode-Plugins，
请按 suian-zcode-title/SKILL.md 的流程完成安装和配置，
包括同仓库 suian-zcode-gateway 的公共配置。完成后提示我先保存工作、处理运行中的任务，
再按公共 skill 的方法完整退出重开 ZCode，验证配置生效。
需要我在 ZCode 界面操作的步骤请告诉我。
```

## 日常怎么用

装好后不需要管它。想让 ZCode 做这些事的时候直接说：

- 「暂停会话自动命名」「恢复会话自动命名」
- 「命名插件换个模型」——更换生成模型或思考档位
- 「命名插件检查一下」——分层诊断，定位到具体哪一环出问题
- 「命名通知总是弹」「通知点了没反应」——通知排障

## 状态与限制

- 命名运行已在 Windows 10/11 实测。需要 Node.js 24+ 和 sqlite3；命名代码本身无 npm 依赖，公共网关单独执行 `npm ci`。
- Stop Hook 在安装时写入，只对之后新建的会话生效；安装前已经开着的会话不会被命名。
- 授权链接与当前 ZCode 窗口绑定，窗口关闭后命名会失败并弹通知，下次开启远控即恢复。
- 模型调用走你自己的账号，每次命名的 token 用量记录在本机，可随时查看。
